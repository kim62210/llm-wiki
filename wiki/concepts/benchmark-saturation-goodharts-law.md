# Benchmark Saturation & Goodhart's Law

"측정 대상이 목표가 되면 좋은 측정이 아니게 된다" -- Goodhart의 법칙은 경제학에서 시작되었지만, 2024~2026년 AI 벤치마크 생태계에서 가장 현실적으로 작동하고 있다. 벤치마크 포화(saturation)는 주요 모델들이 특정 벤치마크에서 거의 만점에 수렴하여 변별력을 잃는 현상이고, Goodhart의 법칙은 이 포화를 가속시키는 구조적 인센티브를 설명한다.

## Goodhart의 법칙이란

Charles Goodhart가 1975년 통화 정책 맥락에서 제안한 원칙이다. 원래 표현은 "관측된 통계적 규칙성은 그것을 통제 목적으로 사용하기 시작하면 붕괴하는 경향이 있다"는 것이며, Marilyn Strathern이 "측정이 목표가 되면 좋은 측정이 아니게 된다"로 일반화했다.

AI 평가에서의 Goodhart 법칙은 이렇게 작동한다:

1. 유용한 벤치마크가 등장한다 ([[mmlu]], [[humaneval]], [[gsm8k]] 등)
2. 연구자와 기업이 이 벤치마크 점수를 모델 품질의 대리 지표(proxy)로 사용한다
3. 높은 벤치마크 점수가 논문 출판, 마케팅, 투자 유치에 직결된다
4. 모델 개발이 벤치마크 최적화에 편향된다
5. 벤치마크 점수가 실제 모델 능력을 반영하지 않게 된다

## 포화의 실제 사례

### MMLU (2020 -> 2025)

2020년 출시 당시 최고 성능은 43.9%였다. 2024년 중반 Claude 3.5 Sonnet, GPT-4o, Llama 3.1 405B 모두 88% 수준에 수렴했다. 상위 모델 간 차이가 1~2%로 줄어 실질적 변별력을 상실했다.

### HumanEval (2021 -> 2025)

Codex의 pass@1 28.8%에서 시작하여, o1이 96.3%를 기록했다. 현재 frontier 모델은 95% 이상이 일반적이며, 164개 문제로는 최상위 모델을 구분할 수 없다.

### GSM8K (2021 -> 2025)

GPT-3의 약 20%에서 시작하여 현재 95% 이상이 달성되었다. 초등 수학 문제가 AI에게 더 이상 어렵지 않게 되었다.

이러한 포화 패턴은 공통적이다: 벤치마크 출시 -> 모델들이 빠르게 점수를 올림 -> 3~5년 내 포화 -> 새 벤치마크 필요.

## 포화가 문제인 이유

**차별화 불가**: 모든 모델이 90% 이상이면 점수 차이가 통계적 노이즈, 정답 오류, 데이터 오염([[benchmark-contamination]])의 영향인지 실제 능력 차이인지 구분할 수 없다.

**인센티브 왜곡**: 벤치마크 점수를 1~2% 올리기 위해 벤치마크 특화 최적화에 리소스를 투입하게 되며, 이는 실제 능력 향상으로 연결되지 않을 수 있다.

**사용자 오도**: "MMLU 90점 모델"이 "MMLU 88점 모델"보다 사용자 경험에서 유의미하게 나은지 알 수 없지만, 마케팅에서는 이 차이를 강조한다.

**연구 방향 왜곡**: 측정 가능한 영역에만 집중하고, 벤치마크로 포착하기 어려운 능력(창의성, 장기 맥락 유지, 도구 사용 유연성)은 과소 투자된다.

## Goodhart의 법칙 변형

Goodhart의 법칙은 AI 평가에서 네 가지 메커니즘으로 나타난다.

**Regressional**: 메트릭과 목표 사이의 상관관계가 극단값에서 무너진다. MMLU 88점과 90점의 차이가 MMLU 50점과 52점의 차이와 같은 의미를 가지지 않는다.

**Extremal**: 메트릭을 극대화하면 메트릭에 포착되지 않는 다른 차원이 희생된다. 예를 들어, 짧은 답변으로 정밀도를 높이면 유용성이 떨어진다.

**Causal**: 메트릭과 목표 사이의 인과 관계가 아닌 상관 관계를 최적화한다. 벤치마크 패턴을 암기하는 것은 벤치마크 점수를 올리지만 일반 능력을 향상시키지 않는다.

**Adversarial**: 메트릭을 의도적으로 게이밍한다. 벤치마크 데이터를 학습에 포함시키거나, 벤치마크 전용 파인튜닝 모델을 출시하는 행위가 여기에 해당한다.

## 대응 방향

벤치마크 포화와 Goodhart 법칙에 대한 대응은 여러 차원에서 진행되고 있다.

### 난이도 상향

- **MMLU-Pro**: 10지선다로 확대, 추론 중심 문제 강화
- **GPQA**: 대학원 수준 전문 지식 요구
- **[[humanity-last-exam]]**: "인류 최후의 시험"이라는 이름에 걸맞은 극난이도

### 동적 벤치마크

- **[[livebench]]**: 월 단위로 문제를 갱신하여 오염과 포화를 동시에 방지
- **LiveCodeBench**: 새로운 프로그래밍 대회 문제를 지속 추가

### 실무 기반 평가

- **[[swe-bench-pro]]**: 실제 GitHub 이슈 해결이라는 실무 태스크 직접 평가
- **Chatbot Arena**: 실사용자의 실시간 선호도 투표로 랭킹 구성
- **[[ab-testing-llms]]**: 프로덕션 환경에서의 직접 비교

### 다차원 평가

단일 점수 대신 여러 차원(정확성, 유용성, 안전성, 창의성 등)을 분리 측정하는 방향이다. [[mt-bench]]의 8개 카테고리별 점수가 초기 사례이며, [[evaluation-harness]]는 수십 개 벤치마크를 동시 실행하여 다차원 프로파일을 구성한다.

## 실무 시사점

- 단일 벤치마크 점수를 절대 기준으로 삼지 않는다
- 포화된 벤치마크의 점수 차이(1~2%)는 노이즈일 수 있다
- 실제 사용 사례에 맞는 자체 평가 셋을 구성한다
- 정적 벤치마크와 동적 벤치마크를 함께 활용한다
- [[human-evaluation-protocols]]로 자동 평가 결과를 검증한다
- 벤치마크 결과를 보고할 때 [[benchmark-contamination]] 가능성을 명시한다

## OpenAI의 Goodhart 측정 연구

OpenAI는 "Measuring Goodhart's Law" 연구에서 보상 모델(reward model) 최적화 과정에서 Goodhart 법칙이 어떻게 발현되는지를 실증적으로 분석했다. RLHF에서 보상 모델 점수를 과도하게 최적화하면 실제 인간 선호도와 괴리가 생기는 현상이 관찰되었으며, 이는 벤치마크 포화와 동일한 구조적 문제다.
