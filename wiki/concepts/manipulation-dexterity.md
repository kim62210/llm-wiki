# 로봇 조작 정교화 (Dexterous Manipulation)

## 개요

로봇 조작 정교화(Dexterous Manipulation)는 다관절 로봇 손(multi-finger hand)이나 정밀 그리퍼를 이용해 인간 수준의 복잡한 물체 조작을 수행하는 기술 분야다. 단순한 픽-앤-플레이스(pick-and-place)를 넘어, 물체를 손 안에서 회전시키거나, 도구를 정교하게 사용하거나, 변형 물체를 다루는 등의 복잡한 조작을 포함한다.

인간의 손은 27개의 뼈와 29개 이상의 관절, 수십 개의 근육을 가지며, 평생에 걸쳐 감각-운동 통합을 학습한다. 이를 로봇으로 재현하는 것은 현대 로봇공학의 핵심 난제 중 하나다.

## 핵심 기술 과제

### 1. 접촉 역학 (Contact Dynamics)

접촉은 로봇 조작에서 가장 비선형적이고 불연속적인 요소다. 접촉의 세 가지 상태(비접촉, 미끄럼, 고착)가 매우 빠르게 전환된다.

- **마찰 모델**: 쿨롱(Coulomb) 마찰 모델의 한계, 실제 마찰의 비등방성
- **변형 접촉**: 고무, 스폰지 등 연성 재질의 접촉 모델링
- **충격 역학**: 빠른 접촉/해제 시의 충격력 처리

[[sim2real-transfer]]에서 접촉 역학은 시뮬레이션과 실제의 가장 큰 불일치 원인이다. 정밀 조작에서 시뮬레이션 학습이 어려운 핵심 이유이기도 하다.

### 2. 감각 피드백

| 감각 | 역할 | 구현 난도 |
|------|------|-----------|
| 촉각 (tactile) | 접촉력, 슬립 감지 | 고난도 |
| 고유감각 (proprioception) | 관절 위치/힘 | 낮음 |
| 시각 | 물체 위치/자세 | 중간 |
| 힘/토크 센서 | 엔드이펙터 힘 | 낮음 |

고급 조작에는 촉각 센서가 거의 필수적이다. GelSight, Digit, DIGIT-T 등의 비전 기반 촉각 센서가 연구에서 활발히 사용된다.

### 3. 다관절 손 제어

5지 로봇 손(예: Shadow Hand, Allegro Hand)은 약 20-24개의 자유도(DoF)를 가진다. 이 고차원 행동 공간을 효율적으로 제어하기 위한 방법이 필요하다.

- **운동학적 제약**: 손가락 간 충돌 회피
- **협응 제어**: 손가락들의 협력 운동 패턴 학습
- **그립 계획**: 물체 형태에 맞는 파지 자세 선택

### 강화 학습 접근 (OpenAI Dactyl 사례)

OpenAI Dactyl은 Shadow Hand로 루빅스 큐브를 한 손으로 맞추는 데 성공한 최초의 사례다. 핵심 기법은 ADR(Automatic Domain Randomization)으로, 물리 파라미터를 자동으로 어렵게 만들어가며 로봇이 적응하게 한다.

- 학습: MuJoCo 시뮬레이션, 수십억 에피소드
- 전이: ADR 도메인 랜덤화로 실제 손에 적용
- 결과: 평균 약 50번 이동으로 큐브 완성

### [[diffusion-policy]] 기반 정교 조작

최근 [[diffusion-policy]]가 정밀 조작 태스크에서 뛰어난 성능을 보이고 있다. 확산 기반 정책은 접촉이 풍부한(contact-rich) 환경에서 다중 모달 행동 분포를 잘 모델링한다.

### [[model-based-rl]] 기반 접근

접촉 역학을 포함한 정확한 세계 모델을 학습하고, 이를 기반으로 정밀 조작 계획을 수립한다. 학습된 모델이 물리 시뮬레이터 역할을 해 실제 데이터 효율을 높일 수 있다.

## 벤치마크 태스크

현재 로봇 정교 조작 연구에서 자주 사용되는 벤치마크들이다.

| 태스크 | 특징 | 사용 하드웨어 |
|--------|------|---------------|
| 루빅스 큐브 조작 | 핸드 내 조작, 기하학적 제약 | Shadow Hand |
| 나사 조이기 | 접촉 풍부, 정밀 정렬 | 이진 그리퍼 |
| 케이블 배선 | 변형 물체, 공간 추론 | 양팔 로봇 |
| 음식 조리 | 다단계, 도구 사용 | ALOHA 등 |
| 젓가락 사용 | 미세 조작, 힘 제어 | 다관절 손 |

## 실무 현황

현재 산업용 로봇은 대부분 구조화된 환경에서 반복적인 조작(용접, 도장, 단순 조립)을 수행한다. 비구조화 환경에서의 범용 정교 조작은 여전히 연구 수준에 머물러 있다. 그러나 [[open-x-embodiment]]과 [[lerobot-framework]] 등을 통한 대규모 데이터 수집과 파운데이션 모델 접근이 이 분야를 빠르게 발전시키고 있다.
