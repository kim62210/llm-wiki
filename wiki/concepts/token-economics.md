## 개요

토큰 경제학(Token Economics)은 LLM API 기반 시스템의 비용 구조를 이해하고 최적화하는 분야다. 토큰은 LLM이 텍스트를 처리하는 기본 단위이며, 대부분의 LLM 서비스는 토큰 단위로 과금한다. 프로덕션 AI 시스템의 운영 비용에서 추론 비용이 차지하는 비중이 크기 때문에, 토큰 경제학의 이해는 [[model-lifecycle-management|모델 수명주기 관리]]와 [[ai-observability-patterns|관측성]]의 핵심 요소다.

## 과금 구조

2025-2026년 기준으로 LLM API 과금은 세 가지 범주로 세분화되었다.

**입력 토큰(Input Tokens)**: 프롬프트, 시스템 메시지, 컨텍스트로 제공되는 토큰에 대한 비용이다. 플래그십 모델 기준 100만 입력 토큰당 약 2-3달러 수준이다.

**출력 토큰(Output Tokens)**: 모델이 생성하는 응답 토큰에 대한 비용이다. 생성은 읽기보다 더 많은 컴퓨트 자원을 소모하므로, 일반적으로 입력 토큰의 3-10배 비용이 부과된다. 이 비대칭성이 엔터프라이즈 비용 모델링에서 가장 중요한 요소다.

**추론 토큰(Reasoning Tokens)**: o1, o3 같은 추론 모델에서 체인-오브-소트(chain-of-thought) 과정에 소모되는 토큰이다. 사용자에게 직접 노출되지 않지만 비용은 발생한다. 이 범주가 2025년 이후 새롭게 등장한 과금 요소다.

## 가격 하락 추세

LLM API 가격은 급격히 하락하고 있다. 2025년 초에서 2026년 초 사이 약 80% 하락했다. GPT-4o 입력 토큰 가격이 100만 토큰당 5달러에서 2.5달러로 떨어진 것이 대표적이다. 오픈소스 모델의 자체 호스팅은 대규모 트래픽에서 API 과금보다 저렴할 수 있지만, GPU 인프라 운영 비용과 엔지니어링 오버헤드를 고려해야 한다.

## 비용 최적화 전략

### 프롬프트 캐싱

[[batch-inference-caching|프롬프트 캐싱]]은 가장 효과적인 비용 절감 기법 중 하나다. Anthropic의 프롬프트 캐싱은 캐시 쓰기 시 기본 입력 비용의 1.25배를 청구하지만, 캐시된 콘텐츠의 후속 읽기는 기본 비용의 0.1배만 청구한다. 반복적으로 사용되는 10,000 토큰 시스템 프롬프트의 경우 첫 요청 이후 90%의 비용을 절감할 수 있다. OpenAI는 자동 캐싱을 기본 활성화하여 50%의 비용 절감을 제공한다.

### 배치 처리

비실시간 워크로드에 대해 배치 엔드포인트를 사용하면 실시간 토큰 비용 대비 약 50%를 절감할 수 있다. OpenAI의 Batch API, Anthropic의 Message Batches 등이 대표적이다.

### 모델 라우팅

모든 요청에 플래그십 모델을 사용할 필요는 없다. 요청의 복잡도에 따라 경량 모델(Flash, Mini 등)과 플래그십 모델을 자동으로 라우팅하면 비용을 크게 줄일 수 있다. OpenRouter, LiteLLM 등의 도구가 멀티 모델 라우팅을 지원한다.

### 출력 최적화

출력 토큰이 입력 토큰보다 비싸므로, 불필요하게 긴 응답을 줄이는 것이 효과적이다. max_tokens 제한, 구조화된 출력(JSON mode), 간결한 응답을 유도하는 프롬프트 설계가 해당한다.

### 프롬프트 압축

긴 컨텍스트를 요약하거나 불필요한 부분을 제거하여 입력 토큰 수를 줄인다. 다만 정보 손실로 인한 품질 저하와의 트레이드오프를 고려해야 한다.

## 비용 모니터링

[[ai-observability-patterns|관측성 체계]]에 토큰 사용량 추적을 통합하는 것이 모범 사례다. 요청별, 기능별, 사용자별 토큰 소비를 추적하면 비용 이상치(anomaly) 탐지와 예산 관리가 가능하다. [[prompt-management-versioning|프롬프트 버전 관리]]와 연계하면, 프롬프트 변경이 비용에 미치는 영향을 정량적으로 측정할 수 있다.

## 토큰 경제학의 전략적 의미

토큰 비용은 AI 시스템의 아키텍처 결정에 직접 영향을 미친다. 긴 컨텍스트 윈도우가 필요한 사용 사례에서는 RAG(검색 증강 생성) vs 롱 컨텍스트 직접 입력의 비용 비교가 필수적이다. 에이전트 시스템에서는 도구 호출 횟수, 멀티턴 대화의 누적 토큰 비용이 운영 비용의 주요 변수가 된다. 결합된 최적화 기법(캐싱 + 배치 + 모델 라우팅)을 적용하면 총 추론 비용을 5-10배까지 줄일 수 있다.
