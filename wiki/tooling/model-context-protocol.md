# MCP 2026 Roadmap & Enterprise Readiness

Model Context Protocol을 엔터프라이즈 배포에 맞게 확장·거버넌스하는 2026년 우선순위 로드맵.

## 왜 지금 중요한가

2026년 3월 공개된 MCP 2026 로드맵이 Transport Evolution, Agent Communication(Tasks primitive), Governance, Enterprise Readiness 4대 우선순위를 명시하면서 Streamable HTTP 무상태화·세션 마이그레이션·SSO·감사 로그를 핵심 이슈로 올렸고, 2025-11-25 스펙이 MCP v2.1 기준선을 고정했다.
