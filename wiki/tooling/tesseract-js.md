# Tesseract.js

브라우저와 Node.js에서 동작하는 OCR 라이브러리다. Tesseract 엔진을 JavaScript/WASM 환경에서 활용할 수 있게 해, 에이전트가 이미지·스크린샷에서 텍스트를 읽는 실험에 자주 등장한다.

## 왜 중요한가

코딩 에이전트는 브라우저 자동화, 스크린샷 분석, 문서 처리 흐름에서 텍스트 추출 도구가 필요하다. Tesseract.js는 별도 네이티브 앱 없이 OCR을 붙일 수 있어 프로토타이핑과 자동화 실험에 자주 선택된다.
