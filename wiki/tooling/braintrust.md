## 개요

Braintrust는 에이전트 트레이스 자동 평가, 실시간 모니터링, 비용 분석을 통합한 AI 옵저버빌리티 플랫폼이다. 자체 개발한 Brainstore 데이터베이스로 기존 대비 80배 빠른 쿼리 성능을 제공하며, 수백만 건의 프로덕션 트레이스를 초 단위로 분석할 수 있다. 이슈 발견부터 근본 원인 진단, 재발 방지까지 하나의 시스템에서 처리하는 것이 핵심 차별점이다. [[llm-observability-platforms|LLM 옵저버빌리티 플랫폼]] 범주에서 평가(evals)와 모니터링을 가장 긴밀하게 통합한 도구이며, [[opentelemetry-genai-semconv|OpenTelemetry 스팬]]을 Braintrust 트레이스로 자동 변환하는 브릿지를 제공한다.

## 핵심 특징

### 자동 트레이스 수집 및 평가

모든 요청에 대해 LLM 호출, 도구 실행, 타이밍 메트릭, 토큰 수, 추정 비용을 포함한 포괄적 트레이스를 자동 수집한다. 테스트 환경에서 사용한 평가기(scorer)를 프로덕션 트레이스에 동일하게 적용하여, 개발-프로덕션 간 품질 측정 일관성을 보장한다.

### 실시간 모니터링

토큰 사용량, 지연 시간, 요청 수, 에러율에 대한 실시간 대시보드를 제공한다. 사용자 코호트, 기능, 커스텀 메타데이터 차원으로 데이터를 슬라이싱하여 세밀한 분석이 가능하다.

### 비용 분석

요청별 프롬프트/완성 토큰, 모델별 비용을 세분화하여 추적한다. 사용자별, 기능별, 커스텀 그룹별 비용 분석으로 과도한 리소스를 소비하는 요청을 식별한다.

### Loop AI 어시스턴트

자연어 설명만으로 커스텀 평가기(scorer)를 자동 생성한다. 프로덕트 매니저가 코딩 없이 품질 기준을 정의할 수 있어, 기술/비기술 팀 간 협업 장벽을 낮춘다.

## 기술 상세

### Brainstore 데이터베이스

AI 워크로드 패턴에 최적화된 자체 개발 데이터베이스로, 기존 범용 DB 대비 80배 빠른 쿼리 성능을 달성한다. 수백만 건의 프로덕션 트레이스를 초 단위로 분석할 수 있다.

### 통합 워크플로우

```mermaid
flowchart LR
    A["프로덕션 트레이스"] --> B["자동 품질 평가"]
    B --> C["이슈 감지"]
    C --> D["근본 원인 진단"]
    D --> E["테스트 케이스 생성"]
    E --> F["재발 방지"]
    F --> A
```

프로덕션 트레이스가 직접 테스트 케이스로 변환되어, 발견된 문제가 회귀 테스트 스위트에 자동 추가된다.

### SDK 및 통합

13개 이상의 프레임워크와 네이티브 통합을 지원한다:

| 카테고리 | 프레임워크 |
|---------|---------|
| 오케스트레이션 | LangChain, LlamaIndex, CrewAI, Autogen |
| AI SDK | Vercel AI SDK, OpenAI Agents SDK, Google ADK, Mastra |
| 구조화 출력 | Instructor, Pydantic AI, DSPy |
| 유틸리티 | LiteLLM |
| 표준 | OpenTelemetry 스팬을 Braintrust 트레이스로 자동 변환 |

**AI Proxy**: 여러 모델 프로바이더를 통합 API로 접근하며 자동 캐싱을 포함한다. 모델 전환 시 코드 변경 없이 프로바이더를 교체할 수 있다.

### 25+ 내장 평가기

정확성, 관련성, 안전성에 대한 25개 이상의 빌트인 스코어러가 제공된다. 테스트 환경에서 정의한 평가기를 프로덕션 트레이스에 동일하게 적용하여, 개발-프로덕션 간 품질 측정의 일관성을 보장한다. 프로덕션에서 발견된 문제 트레이스는 자동으로 테스트 케이스로 변환되어 회귀 테스트 스위트에 추가된다.

### Loop AI 어시스턴트 상세

Loop는 단순한 스코어러 생성기를 넘어 능동적 옵저버빌리티 어시스턴트로 기능한다. 로그를 분석하여 패턴을 발견하면 새로운 옵저버빌리티 메트릭을 제안한다. 자연어 질의를 지원하여 "지난 주에 [[hallucination|환각]]이 더 많았나?"와 같은 질문에 즉시 응답할 수 있다. 프로덕트 매니저가 코딩 없이 품질 기준을 정의할 수 있어, 기술/비기술 팀 간 협업 장벽을 크게 낮춘다.

### 도입 시 고려사항

**Braintrust 적합 케이스**:
- 빠른 쿼리 성능이 필요한 대규모 프로덕션 환경 (수백만 트레이스)
- 비기술 팀원이 평가 기준을 직접 정의해야 하는 조직
- 다수의 AI 프레임워크를 혼용하는 팀 (13개 이상 네이티브 통합)
- 모델 프로바이더를 자주 전환하는 환경 (AI Proxy)

**Langfuse/오픈소스 적합 케이스**:
- 데이터 주권이 최우선인 환경 (전 플랜 셀프호스팅)
- DevOps 역량이 충분하고 인프라 커스터마이제이션이 필요한 팀
- 예산 제약이 있는 스타트업 (셀프호스팅 무제한)

### 자동 트레이스의 수집 범위

모든 요청에 대해 다음 메트릭이 자동 수집된다: 전체 소요 시간(duration), LLM 소요 시간(LLM duration), 첫 토큰까지 시간(time to first token), LLM 호출 수, 도구 호출 수, 에러 발생 여부. 이 데이터를 사용자 코호트, 기능, 커스텀 메타데이터 차원으로 슬라이싱하여 세밀한 분석이 가능하다.
