# The 2026 MCP Roadmap

MCP 프로젝트가 2026년에 무엇을 우선 과제로 두는지 설명하는 공식 로드맵 글 요약이다. release milestone보다 **priority area 중심**으로 재구성되었다는 점이 특징이다.

## 핵심 내용

- Streamable HTTP와 session model의 확장
- agent communication / tasks primitive
- governance maturation
- enterprise readiness

이 네 축이 maintainer capacity가 집중되는 우선순위로 제시된다.

## 왜 중요한가

이 문서는 MCP가 실험적 로컬 툴 연결을 넘어, **실제 조직 배포와 운영 가능한 프로토콜**로 이동하고 있음을 보여준다.

## 실무 적용 관점

로드맵 문서는 기능 목록보다 “지금 MCP 커뮤니티가 어떤 문제를 가장 큰 병목으로 보고 있는가”를 알려준다. 따라서 MCP를 도입하는 팀은 스펙 현재 상태뿐 아니라 이 로드맵의 우선순위도 같이 봐야 한다.
