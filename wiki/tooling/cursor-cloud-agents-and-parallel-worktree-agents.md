# Cursor Cloud Agents & Parallel Worktree Agents

로컬·worktree·클라우드 VM·원격 SSH 환경에서 다수의 코딩 에이전트를 병렬 실행하는 Cursor의 에이전트 우선 UI.

## 왜 지금 중요한가

2026년 4월 2일 Cursor 3.0이 Agents Window·Design Mode·`/worktree`·`/best-of-n` 명령·Await 툴을 정식 출시했고, 3월 25일에는 self-hosted cloud agent(회사 네트워크 안에서 툴 실행)까지 등장하면서 "에이전트 병렬 실행"이 본격적 프로덕션 워크플로가 됐다.
