## Abstract

SKILL0 proposes an in-context agentic reinforcement learning framework designed for skill internalization. The key idea is enabling language models to internalize agent skills into model parameters rather than relying on runtime skill retrieval. Through progressive curriculum learning that gradually removes skill context, SKILL0 teaches agents to operate autonomously.

## Key Points

- Progressive curriculum learning that gradually removes skill context to force internalization
- Achieves +9.7% improvement over standard RL baseline on ALFWorld
- Achieves +6.6% improvement on Search-QA
- Demonstrates efficient token usage by reducing reliance on in-context examples
- Bridges gap between in-context learning and parameter-level skill acquisition
