## Abstract

코딩 에이전트를 ERP 비즈니스 프로세스 자동화에 적용하여 범용성을 평가한 연구로, Agentic Labs에서 수행되었다. 단순 태스크는 처리 가능하지만 복잡한 태스크에서는 도메인 로직과 코드 실행 간 연결이 핵심 병목임을 발견했다. 기존 코딩 에이전트 벤치마크가 이러한 범용 에이전시 능력을 평가하지 못하는 평가 격차도 지적한다.

## Key Points

- Coding agents tested on ERP business process automation
- Simple tasks OK, complex tasks show characteristic failures
- Key bottleneck: bridging domain logic and code execution
- Evaluation gap in existing coding agent benchmarks
- From Agentic Labs
