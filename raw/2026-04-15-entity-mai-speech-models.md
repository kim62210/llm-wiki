## Overview

Microsoft의 MAI Superintelligence 팀(Mustafa Suleyman 리드)이 개발한 파운데이셔널 모델 3종: MAI-Transcribe-1, MAI-Voice-1, MAI-Image-2. Copilot, Bing, PowerPoint, Azure Speech 등에서 이미 사용 중.

## MAI-Transcribe-1

- SOTA 음성-텍스트 전사: FLEURS 벤치마크 상위 25개 언어 지원
- 실제 환경(노이즈, 다화자)에서 세계 최고 품질
- 배치 전사 속도: 기존 Azure Fast 대비 2.5배
- 가격: $0.36 USD/시간

## MAI-Voice-1

- 최상위 음성 생성 모델
- 자연스럽고 사실적인 음성: 뉘앙스, 감정 범위, 표현력 보존
- 단일 GPU에서 60초 음성을 1초 미만에 생성
- 긴 콘텐츠에서도 화자 정체성 유지
- 가격: $22 USD/1M 문자

## MAI-Image-2

- 이미지 생성 모델 (3종 중 하나)

## Context

- OpenAI, Google과의 직접 경쟁을 위한 Microsoft의 자체 AI 모델 스택 확장
- 2025년 11월 MAI Superintelligence 팀 결성 발표 이후 첫 성과물
