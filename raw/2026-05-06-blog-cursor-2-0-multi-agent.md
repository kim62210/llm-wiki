# Introducing Cursor 2.0 and Composer

## 주요 발표

Cursor 2.0은 에이전트 기반 코딩 워크플로우를 강화하는 두 가지 메이저 업데이트.

### 1. Composer 모델

- Cursor의 첫 자체 코딩 모델
- 비교 모델 대비 **4배 빠른 성능**
- 30초 미만 인터랙션
- 전체 코드베이스 시맨틱 검색
- 다단계 코딩 작업 능력

### 2. Multi-Agent Interface

UI가 파일 브라우징보다 에이전트 우선으로 재설계.

- **다수 에이전트 병행 운영**: git worktrees 또는 원격 머신
- 충돌 회피
- 핵심 발견: "동일 문제에 병렬 모델 실행 후 우수 출력 선택이 복잡 작업에서 결과를 크게 개선"

## 추가 능력

### Code Review
에이전트 생성 변경 검토 효율화 - 더 깊은 코드 검사 옵션 포함.

### Browser Testing
네이티브 브라우저 도구로 Cursor가 구현 테스트 + 결과 반복 정제.

### Availability
- cursor.com/download
- 전체 기능은 changelog 참조

## 메모

- 게시일: 2025년 10월 29일
- 읽기 시간: 3분
- Cursor 2.0의 핵심 신기능: Composer 모델 + multi-agent 워크플로우
- "agent-first architecture"로의 전환점
- Composer는 동일 발표일 별도 블로그 "Composer: Building a fast frontier model with RL"에서 깊이 다룸
