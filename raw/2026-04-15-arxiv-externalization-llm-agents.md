## Abstract

Large language model agents are increasingly built less by changing model weights than by reorganizing the runtime around them. Capabilities that earlier systems expected the model to recover internally are now externalized into memory stores, reusable skills, interaction protocols, and the surrounding harness.

Under this view:
- Memory externalizes state across time
- Skills externalize procedural expertise
- Protocols externalize interaction structure
- Harness engineering serves as the unification layer coordinating them into governed execution

## Key Points

- 핵심 기여: "외부화(externalization)"를 LLM 에이전트 발전의 통합 원리로 제시
- 4대 축: 메모리, 스킬, 프로토콜, 하네스 엔지니어링
- 파라메트릭 vs 외부화 능력 간 트레이드오프 분석
- 자기 진화하는 하네스, 공유 에이전트 인프라 등 미래 방향 제시
- 평가, 거버넌스, 모델-외부 인프라 공진화의 미해결 과제 논의
