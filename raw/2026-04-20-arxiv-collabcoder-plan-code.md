## Abstract

CollabCoder는 계획 모듈과 코드 모듈 간 협업적 의사결정을 통한 계획-코드 공동 진화(Plan-Code Co-Evolution) 프레임워크다. LiveCodeBench와 xCodeEval에서 11-20% 성능 향상을 달성하면서 실행당 API 호출을 4-10회 절감하는 효율적인 코드 생성 방식을 제안한다.

## Key Points

- Plan-Code Co-Evolution framework
- Multi-agent collaboration between plan module and code module
- 11-20% improvement on LiveCodeBench and xCodeEval
- Reduces API calls by 4-10 per execution
- Dynamic collaborative decision-making
